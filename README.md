# 🖥️ System Monitor

A modern, neon-themed system monitor for Linux built with **PySide6** and **psutil**.

![Python](https://img.shields.io/badge/Python-3.10+-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Linux-orange)

##  Features

- 📊 Real-time monitoring of CPU, GPU, RAM, and Disks
- 🌡️ Temperature and fan speed tracking
-  Per-core CPU usage graphs
- 💾 VRAM and disk I/O statistics
- 🎨 Beautiful neon/cyberpunk dark theme
- ⚡ Non-blocking background monitoring thread
